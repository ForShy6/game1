# 猜数字小游戏（Guess Number）

一个用 Python 编写的命令行猜数字小游戏：程序随机生成 1-100 之间的整数，玩家反复猜测，程序提示"大了"或"小了"，直到猜中并统计所用的猜测次数。

## 游戏玩法

1. 程序运行后，会自动生成一个 1 到 100 之间（含 1 和 100）的随机整数作为答案；
2. 在提示符后输入一个数字并按 Enter 提交；
3. 程序比较后给出三种反馈之一：`大了`、`小了`、`猜对了`；
4. 猜中后显示答案和本局总猜测次数，程序随即结束。

示例交互过程：

```text
欢迎来到猜数字游戏！
我已经想好了一个 1 到 100 之间的整数，开始猜吧！
请输入你猜测的数字（1-100）：50
小了，再往大猜一猜！
请输入你猜测的数字（1-100）：75
大了，再往小猜一猜！
请输入你猜测的数字（1-100）：63
恭喜你，猜对了！答案就是 63。
本局你一共猜了 3 次。
```

最优策略是"二分查找"：每次猜当前范围的中点，1-100 的范围内最多 7 次必中。

## 核心特色

- **单文件实现**：全部逻辑集中在 `guess_number.py` 一个文件中，不拆分模块，便于阅读；
- **零第三方依赖**：只使用 Python 标准库，装好 Python 即可运行，无需 `pip install`；
- **输入容错**：非整数输入、超出 1-100 范围的数字都会被拦截并给出中文提示；
- **计数规则清晰**：无效输入不计入猜测次数，只统计真正参与比较的次数；
- **面向初学者**：变量命名直白，关键步骤均有中文注释，流程为"生成答案 → 循环猜测 → 猜中结束"。

## 操作说明

| 操作 | 说明 |
| --- | --- |
| 输入数字 + Enter | 提交一次猜测。必须是整数，且落在 1-100 之间 |
| 输入非整数（如 `abc`、`3.5`） | 提示"输入无效"，不计入次数，可继续输入 |
| 输入范围外的数字（如 `0`、`150`） | 提示"超出范围"，不计入次数，可继续输入 |
| 输入前后带空格 | 程序会自动去除首尾空白，不影响判断 |
| Ctrl + C | 强制中断程序（会抛出 `KeyboardInterrupt`，程序未做捕获） |

## 注意事项与已知限制

- **一次运行只玩一局**：猜中后 `break` 跳出循环、程序结束，想再来一局需要重新执行命令；
- **没有中途退出指令**：未实现 `quit`、`exit` 之类的退出命令，猜中前只能靠 Ctrl + C 强制中断；
- **中断时会有报错信息**：Ctrl + C 会产生 `KeyboardInterrupt`，输入流被关闭（如管道输入结束）会产生 `EOFError`，程序未对这些异常做处理，属当前实现的正常表现；
- **只接受整数**：输入 `50.5` 这类小数会被判为无效输入，而不是四舍五入处理；
- **答案是闭区间**：`random.randint(1, 100)` 生成的数字包含 1 和 100 两端；
- **无记录功能**：不保存历史成绩，关闭程序后本局结果即丢失；
- **难度固定**：答案范围写死为 1-100，如需调整需修改源码中的 `randint(1, 100)` 与范围判断条件。
